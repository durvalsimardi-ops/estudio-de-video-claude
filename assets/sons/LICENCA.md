# Licença dos sons

Todos os arquivos desta pasta (`clique.wav`, `pop.wav`, `whoosh.wav`, `brilho.wav`, `impacto.wav`, `subida.wav` e `kit.json`) são gerados pelo próprio repositório, por código, com o script `.claude/skills/som/gerar_kit.py`. Não há gravação nem amostra de terceiros dentro deles.

Uso livre: pode usar, alterar e publicar em qualquer vídeo, inclusive comercial, sem crédito e sem pagar nada.

Para gerar de novo (sai sempre igual):

```
.venv/bin/python .claude/skills/som/gerar_kit.py
```
